# Day 002: RestAssured API Schema Validation

## 💡 Concept
API testing goes beyond HTTP 200 checks. Validating schema structures ensures contract compliance between frontend and backend services.

## 🚀 Key Takeaways
- Use JSON Schema Validation to catch contract breaking changes early in CI/CD.
- Leverage RestAssured fluent BDD syntax (`given()`, `when()`, `then()`).
